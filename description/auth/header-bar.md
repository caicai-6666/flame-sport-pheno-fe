# 顶部导航与头像

本文说明顶部用户栏的导航职责、钉钉退出行为、头像接口契约，以及图片资源释放和失败降级方式。

## 组件位置

```text
src/components/HeaderBar.vue
src/api/avatar.js
src/api/dingtalkNavigation.js
```

`HeaderBar` 展示退出按钮、品牌 Logo、项目详情页返回按钮和当前用户头像。退出按钮固定在左侧首位，使用关机图标和轻量玻璃质感；项目详情页返回按钮只负责返回项目列表，两种操作不会混用。

品牌 Logo 使用带 Alpha 通道的无损 `src/assets/logo.webp`，组件不为图片绘制额外实色背景，透明区域直接显示 Header 背景。生产构建会生成带内容哈希的 WebP 文件，并由容器 Nginx 设置一年不可变缓存；Logo 更新后文件哈希变化，浏览器会自动获取新版本。

全屏模式通过 `viewport-fit=cover` 将页面扩展至设备安全区。Header 从屏幕顶部开始绘制背景，并把 `safe-area-inset-top` 完整计入高度和上内边距，避免按钮进入状态栏或刘海区域；安全区之后只额外保留 `8px` 顶部间距，无安全区设备同样使用 `8px`。Header 的基础高度为 `64px`，与内容视口起点统一读取 `--header-height`，因此缩短顶部间距时不会在底部重新产生固定空带。

Header 底部不使用透明渐隐遮罩；首屏视觉间距由路由滚动容器自身的顶部内边距提供，滚动后也不会进入 Header 下方或被固定区域遮盖。Header 的空白区域不接收指针事件，只有退出、返回和头像控件可交互。

根页面不参与业务内容滚动，底部导航以悬浮层覆盖在内容滚动视口上方，因此旧版 WebView 的根页面回弹不会带动固定导航。

## 退出应用

用户点击左上角关机按钮，或从屏幕左右边缘向内完成一次明确的水平滑动时，前端统一调用钉钉 `biz.navigation.close` 关闭当前 H5 页面。边缘手势需从距应用边缘 `24px` 内开始、在 `900ms` 内向内移动至少 `72px`，且水平位移明显大于垂直位移，避免正常纵向滚动和页面切换动画误触。

边缘手势识别后会阻止 WebView 继续处理本次移动，防止先退回前端上一条路由。主导航、项目详情和过往审核等应用内跳转统一使用 `router.replace`，不在浏览器中累积可供系统边缘返回的应用内历史，作为系统手势早于页面事件时的兜底。页面内已有返回按钮继续执行明确的业务返回，不依赖浏览器历史。

退出请求进行中按钮进入等待态并拒绝重复触发；JSAPI 缺失、调用失败或超时后，页面保留当前状态，并在顶部显示可自动消失的错误提示。

> **注意**
>
> `biz.navigation.close` 面向钉钉移动端 H5。普通浏览器开发环境无法由页面脚本可靠关闭当前标签页，因此会显示环境不支持提示，不模拟清空登录态或跳转到其他页面。

## 获取用户头像

### `GET /image/avatar` 接口定义

```http
GET /image/avatar
```

### 请求参数

请求头如下：

```http
Authorization: <auth_code>
```

Query 参数和请求体均无。

### 成功响应

响应为图片二进制数据，建议后端设置：

```http
Content-Type: image/png
```

或：

```http
Content-Type: image/jpeg
```

前端以 `Blob` 接收：

```js
const avatarBlob = await getAvatarImage();
const avatarUrl = URL.createObjectURL(avatarBlob);
```

### 异常处理

接口超时后会由公共请求层在 400 ms、800 ms 后各自动重试一次；三次均超时或发生其他错误时不阻塞页面，头像保持默认占位文本 `PH`。
