# 商城页面

## 当前状态

`ShopPage` 已接入真实数据。

已接入：

- 奖品列表查询
- 奖品图片查询
- 按兑换积分分档展示奖品
- 积分流水查询
- 可用积分根据最新积分流水计算
- 商品兑换扣减
- 赛季开始前 N 个自然日的兑换窗口控制（默认 7 天，由环境变量配置）
- 页面路由 `KeepAlive` 缓存
- 商品图片队列随商城商品面板可见性暂停和恢复
- 顶部卡片使用共享 PixiJS 液体背景的青绿色变体，强化纵向流动和冷色高光；WebGL 不可用或开启“减少动态效果”时使用深青色静态渐变
