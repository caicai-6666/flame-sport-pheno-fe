# Flame Winter Pheno 文档地图

> **文档目的**
>
> 本文档集中维护 `description/` 下的文档入口和推荐阅读顺序，帮助开发者按任务范围定位项目规则、业务流程、接口约定和数据定义。

## 1. 使用说明

开始开发前，应先阅读 [项目概况](project.md)，了解业务闭环、当前实现状态和前端编排，再阅读 [项目文档撰写规范](document-style.md) 与 [通用接口约定](conventions/api-response.md)。

处理具体功能时，只需继续阅读对应业务域文档，并结合相关 View、Component、API 和 State 检查完整数据流。`db/` 下的文档是数据库事实来源，默认只读；只有任务涉及接口字段、数据关系或后端契约时才需要阅读相关文件。

---

## 9. 视觉资料

- [`preview-image/`](preview-image/) 保存当前主要页面预览图，用于确认整体视觉和页面结构。
- 仓库根目录的 [`concept/`](../concept/) 保存早期线框和挑战规则图，用于理解原始产品意图，不代表当前页面的最终实现。

修改页面时，应以当前组件、对应业务文档和最新预览图为共同依据。
