# 历史页面

## 当前状态

`HistoryPage` 已接入真实数据。

已接入：

- 当前赛季参与状态检查
- 当前赛季上传记录查询
- 当前与过往赛季记录支持按压查看受鉴权保护的凭证原图
- 可查看原图的记录采用抬起式按压反馈
- 当前赛季各项目完成进度查询
- 结算中赛季可补传资格查询、置顶去重展示，以及只读的资格数量概况
- 可补传记录卡翻面补交：仅选择图片和填写备注，支持多图拼接预览与二次确认提交
- 未参与本赛季时，直接展示可补传记录卡和过往赛季上传记录
- 过往赛季上传记录查询
- `HistoryPage` 及过往赛季上传记录页已接入路由 `KeepAlive`
- 当前与过往赛季页面的顶部卡片共用 PixiJS 液体背景，历史页采用偏纵向、节奏较沉稳的琥珀橙变体；WebGL 不可用或开启“减少动态效果”时使用深琥珀色静态渐变
- 当前、过往和可补传运动记录统一使用短距离双层阴影；滚动列表为阴影保留四周空间，触摸设备不启用可能残留的大幅悬停阴影，3D 补传卡仅由当前可见面绘制阴影

赛季进度条使用后端返回的完成比例，不再使用前端模拟百分比。进度卡与可补传记录概况共用紫色、珊瑚色和浅金色液体背景；切换当前与过往记录时卡片保持原位，仅内部内容沿切换方向滑动。未参与本赛季时直接展示该只读概况卡。
